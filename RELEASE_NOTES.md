### 🚀 Homework Solver v1.0.0 — Pure Groq LPU Engine

A high-speed, unobtrusive screen-snipping browser assistant for students, developers, and test-takers powered by Groq LPU vision inference (`qwen/qwen3.8-27b`).

---

### ⚡ Highlights & Key Features
- **Dedicated Groq Engine**: Pure high-throughput vision inference with round-robin key rotation and zero bloat.
- **🔍 Inline Step-by-Step Derivations**: Instant deep-dive into full derivations from MCQ/Short answers without re-snipping.
- **⚡ Display-Synced Streaming**: `requestAnimationFrame` throttling eliminating micro-stutters during 300+ token/s output speeds.
- **⏳ Smart 60s Rate-Limit (HTTP 429) Backoff Memory**: Proactive key cooldown and healthy key prioritization.
- **🎨 Acrylic Sand & Warm Espresso UI**: Frosted glassmorphic panels, Plus Jakarta Sans typography, and terracotta bronze accents.
- **🖱️ Snipping Controls**: Right-click/<kbd>Esc</kbd> instant cancellation and crosshair/default/custom cursor presets.
- **⚙️ Full-Tab Settings Dashboard**: Key connectivity tester, cursor previewer, and JSON backup/restore.

---

### 📦 How to Install Unpacked
1. Download `homework-extension-v1.0.0.zip` below and extract it.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
5. Add your free Groq API key in the extension settings and press <kbd>Alt</kbd>+<kbd>C</kbd> to start snipping!
